# 조간 논문 — 디자인 시스템 · 화면 명세

컨셉은 **조간신문**이다. 따뜻한 아이보리 지면에 명조체 헤드라인, 그 위에 산세리프 본문. 출근길 지하철에서 한 손으로 훑을 때 제목과 본문의 위계가 즉시 보이는 것이 목표다. 오디오 모드만 어두운 화면으로 반전한다 — 서 있거나 눈을 쉬게 할 때 쓰는 화면이라서다.

아래 값은 시안에서 실제로 쓴 값이다. `tailwind.config.ts`의 theme에 그대로 등록하고, 컴포넌트에 hex를 직접 쓰지 않는다.

## 4. 규칙

- **아이콘은 인라인 스트로크 SVG.** 이모지 금지. stroke-width 1.3~1.6, `stroke-linecap: round`
- **가짜 상태바를 그리지 않는다.** 실제 브라우저 크롬이 그 자리를 차지한다
- **배지는 두 종류뿐** — 🟢 `검증됨`(체크 원) / 🟡 `심사 전`(경고 삼각형). 점수 숫자를 배지에 넣지 않는다
- **신뢰도 근거 칩**은 목록 단계에서 이미 보여야 한다. `동료심사 통과` `코드 공개` `베이스라인 5종` `표본 214명`, 그리고 부정 신호는 `caution` 색으로 `코드 비공개` `관찰연구`
- **접근성** — 실제 `<button>` / `<a href>` / `<input>` + `<label>`을 쓴다. `div`에 `role`이나 `onClick`을 붙이지 않는다 (Tab 이동이 안 된다). 아이콘 전용 버튼에 `aria-label`
- 대비 — 본문 4.5:1, 24px 이상 3:1. `ink-muted`(#625C50)가 `paper` 위 대비의 하한선이다. 그보다 밝은 회색을 본문에 쓰지 않는다

## 5. 반응형

같은 라우트가 브레이크포인트에 따라 레이아웃만 바뀐다. 데이터는 하나다.

| 폭 | 레이아웃 |
|---|---|
| `< 720px` — 폰 | 1칼럼. 하단 탭 내비게이션. 사이드 정보(필터, 신뢰도 상세)는 별도 화면이나 접힘으로 |
| `720 ~ 1080px` — 태블릿 | 본문 + 우측 도구 레일 2단. 좌측 목차는 서랍(drawer) |
| `≥ 1080px` — 데스크톱 | 좌 목차 · 중앙 본문 · 우 도구 3단 |

본문 칼럼 `max-width: 660px`는 모든 구간에 적용한다.

## 7. 구현 메모

- **PDF 뷰어가 가장 까다로운 지점이다.** 원문을 앱 안에서 렌더할지(pdf.js) 인용 위치만 표시하고 새 탭으로 넘길지. **초기 버전은 후자를 권한다** — 정독 화면은 그 전제로 그려져 있다. `quotes[].locator`가 PDF 앵커 역할을 한다
- 오프라인 — 새벽 배치가 끝나면 그날 브리핑의 요약·오디오·이미지를 Service Worker 캐시에 프리빌드한다. 터널에서도 열려야 한다
- 알림 — 고정 시각이 아니라 사용자가 설정한 출발 시간 5분 전
- 연속 기록(`🔥 12일째`)은 습관 장치다. 가볍게 두고, 끊겼을 때 죄책감을 주는 문구는 쓰지 않는다
